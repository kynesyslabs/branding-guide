Foundations

Color

Dark-first. One accent: violet — identity and action alike. Data and secondary emphasis use the neutral text tokens. Click any swatch to copy its hex. Status names remain compatible; meaning comes from visible labels and icons, never color alone.

Source: demos.network, captured 2026-09-28. Extra semantic colors on the site are deliberately excluded; this is not exact color parity. Source details and palette policy.

Install

Import once, reference tokens everywhere. Plain CSS or Tailwind.

Plain CSS

<link rel="stylesheet" href="brand/tokens.css">
<link rel="stylesheet" href="brand/fonts.css">
<link rel="stylesheet" href="brand/components.css">

Tailwind

// tailwind.config.js
module.exports = {
  presets: [require('./brand/tailwind.preset.js')],
  content: ['./src/**/*.{html,js,ts,jsx,tsx}'],
};

The two verified fonts load from Google Fonts via fonts.css. Generic fallbacks work offline. See the guide for self-hosting and source details.
